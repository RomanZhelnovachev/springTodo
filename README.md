# Spring ToDo

RESTful API веб-сервиса с использованием Spring Boot. Разработано TODO приложение, которое позволяет вести список дел

**Описание:**<br>
- [x] В качестве БД используется PostgreSQL<br>
- [x] Для миграций используется Flyway <br>
- [x] Репозиторий с помощью JdbcTemplate от Spring’а. <br>
- [x] Реализованы юнит и интеграционные тесты <br>
- [x] Добавлено кеширование с использованием spring cache и redis <br>
- [x] Описание API с помощью OpenAPI и Swagger <br>
- [x] Реализована валидация DTO <br>
- [x] limit-offset пагинацию для получения всех дел <br>
